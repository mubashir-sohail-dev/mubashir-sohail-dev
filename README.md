### 🌟 Featured Projects

#### 🏆 [ExamCraft](https://github.com/mubashir-sohail-dev/ExamCraft) — *Zero-Hallucination Textbook RAG Assessment Studio*
> **Monorepo Architecture:** Flutter Client + Next.js 15 Web Studio + FastAPI Backend + Google Gemini + Qdrant + ReportLab

* **Problem:** Educators spend countless hours every semester manually writing syllabus-compliant examination papers, frequently running into AI hallucinations or off-syllabus drafting when using generic LLMs.
* **Solution:** Developed an end-to-end multi-platform assessment engine with strict zero-hallucination guarantees for secondary education (Grade 9–12).
* **Technical Highlights:**
  * **100% Verifiable Grounding:** Every generated question includes strict textbook page citations and source snippets.
  * **Multi-Platform Access:** Cross-platform Flutter mobile client for on-the-go management paired with a responsive Next.js 15 web studio.
  * **Vector Compilation:** Automated publication-grade PDF exam generation with school headers and watermark layouts using ReportLab.
* **Tech Stack:** `Dart` `Flutter` `Next.js 15` `React` `FastAPI` `Python` `Google Gemini` `RAG` `ReportLab`

---

#### 🔍 [omniquery-ai](https://github.com/mubashir-sohail-dev/omniquery-ai) — *Self-Healing Natural Language to T-SQL Engine*
> **Stack:** Python, Qdrant Hybrid Search, FastEmbed, Groq LPUs, AdventureWorks OLTP

* **Problem:** Complex relational database schemas with hundreds of interconnected PK/FK constraints present massive hallucination and syntax degradation hurdles for standard Text-to-SQL solutions.
* **Solution:** Built an enterprise Text-to-SQL pipeline targeting Microsoft AdventureWorks using hybrid schema search and self-correcting execution loops.
* **Technical Highlights:**
  * **Hybrid Schema Retrieval:** Combined dense vector embeddings with sparse BM25 indexing via FastEmbed and Qdrant.
  * **Iterative Self-Repair:** Engineered an automated LLM error reflection loop that executes SQL against the database, catches syntax or schema exceptions, and repairs queries iteratively.
* **Tech Stack:** `Python` `Qdrant` `FastEmbed` `Groq` `Text-to-SQL` `Relational Schemas`

---

#### 📚 [omnirag](https://github.com/mubashir-sohail-dev/omnirag) — *Dense RAG System with OCR & Anti-Hallucination Guardrails*
> **Stack:** Python, LangChain, Vector Embeddings, PDF & OCR Ingestion

* **Problem:** Ingestion pipelines routinely break when documents contain mixed raster scans, handwritten artifacts, or corrupted text streams.
* **Solution:** Architected a production-ready Dense Retrieval-Augmented Generation pipeline featuring dual-mode ingestion (native PDF text parser + OCR fallback).
* **Technical Highlights:**
  * Automated chunking with semantic overlap preservation.
  * Anti-hallucination verification guardrails ensuring answers strictly correlate with document embeddings.
* **Tech Stack:** `Python` `LangChain` `Vector Search` `OCR Pipeline` `Document Parsing`

#### 📊 [supermarket-sales-intelligence](https://github.com/mubashir-sohail-dev/supermarket-sales-intelligence) — *Retail BI Suite & Customer Segmentation*
> **Stack:** Python, Streamlit, Pandas, SciPy, ANOVA Testing, RFM Segmentation
